
# ODS Classic ML — Практические задания

Репозиторий содержит домашние задания, выполненные в рамках курса [ODS Classic ML](https://ods.ai/tracks/classic-models-autumn26).

Здесь собраны практические примеры работы с данными, построения моделей машинного обучения, оценки их качества и анализа результатов.

### 01. Линейная регрессия

Линейные модели, статистический анализ, предобработка данных, регуляризация Ridge и Lasso, оценка качества регрессии.

Градиентный спуск, логистическая регрессия, калибровка вероятностей, метрики классификации и подбор порога принятия решения.

[Перейти к заданию](./02-logistic-regression/)

### 03. Предобработка данных и методы машинного обучения

Обработка пропущенных значений, анализ тональности текстов, прогнозирование временных рядов и отбор признаков.

[Перейти к заданию](./03-data-processing-and-ml/)

## Инструменты

Python, NumPy, pandas, scikit-learn, statsmodels, Matplotlib, Seaborn, NLTK и другие библиотеки, используемые в заданиях.
